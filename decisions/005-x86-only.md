# 005 Contest machines are x86 PCs only

- **Status:** accepted
- **Date:** 2026-11-10

## Context
The stick boots a Linux image from USB on contestants' laptops and desktops. The image is built for
x86-64. Apple Silicon Macs cannot boot Linux from a USB drive.

## Decision
Supported contest machines are x86 PCs that boot from USB (UEFI or BIOS). Apple Silicon is not supported.

## Consequences
- One image and one agent target (`x86_64-unknown-linux-musl`). The admin app targets Windows first.
- Organizers must give contestants with Apple Silicon laptops a different machine.
- Some "Secured-core" laptops need "Allow Microsoft 3rd Party UEFI CA" enabled in the firmware settings.

## Alternatives considered
- **ARM image for Macs:** it cannot be booted from USB on Apple Silicon at all.
- **Virtual machines instead of sticks:** the host system is outside our control, so it proves nothing
  about the machine.
