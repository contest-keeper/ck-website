# P0.4 Decision records

**Depends on:** P0.1 · **Next:** A.1

## Why
Short written records of the big decisions, so new contributors understand *why* things are the way
they are and don't undo them by accident.

## Context
- All decisions so far are in context.md §2. Each record is one page: context, decision,
  consequences, alternatives considered.
- Format: `decisions/NNN-title.md` in ck-website (Architecture Decision Record).

## Small steps
- [x] **P0.4.1** `decisions/000-template.md`.
- [x] **P0.4.2** `001-settings-on-efi-partition.md` – why settings go on the FAT EFI partition
  (Windows can write it natively; no image rebuild per contest; team reset wipes the ICPC partition;
  EFI mounted root-only so contestants can't read the key).
- [x] **P0.4.3** `002-signed-reports.md` – every stick has its own key; every report is signed
  (HMAC now, Ed25519 in H.1); server records its own receive time.
- [x] **P0.4.4** `003-squid-icap-capture.md` – capture through the existing Squid + ICAP instead of
  replacing the proxy or using a browser extension; needs the network lock (D.4) to be trustworthy.
- [x] **P0.4.5** `004-naming.md` – fixed `ck-*` internals; admin-chosen branding.
- [x] **P0.4.6** `005-x86-only.md` – why Apple Silicon is out (no USB Linux boot).
- [x] **P0.4.7** `006-rust-everywhere.md` – Rust for Keeper OS, Forge and Hub; Svelte 5 for UIs (matches the extension).
- [x] **P0.4.8** `007-names.md` – Contest Keeper, Keeper OS / Forge / Hub / Extension; repository rule `ck-<part>`.
