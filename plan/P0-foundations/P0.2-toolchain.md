# P0.2 Toolchain

**Depends on:** P0.1 · **Next:** P0.3

## Why
Everyone (and CI) builds the same way: Windows binaries for the admin tools, a static Linux binary
for the stick.

## Context
- Already installed on this PC (context.md §6): Rust 1.99.1 with default toolchain
  `stable-x86_64-pc-windows-gnu`, target `x86_64-unknown-linux-musl`, Zig 0.17.0, `cargo-zigbuild`
  0.24.1, WinLibs GCC. No MSVC C++ tools – that's why the GNU toolchain is used.
- The agent must be a **static** Linux binary: the stick's Ubuntu should not need any extra library.
  musl + Zig gives that, including crates with C parts (e.g. `ring` for TLS).
- Workspace layout is in context.md §3. Start with an empty workspace plus the crate folders.
